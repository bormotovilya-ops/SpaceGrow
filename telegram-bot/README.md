# Telegram-бот для Пространство развития MiniApp

Бот открывает сайт Пространство развития как MiniApp в Telegram.

## Быстрая настройка на Railway

### 1. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота (формат: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Настройка на Railway

1. Зарегистрируйтесь на [Railway.app](https://railway.app) (можно через GitHub)
2. Нажмите "New Project"
3. Выберите "Deploy from GitHub repo"
4. Подключите репозиторий `SpaceGrow`
5. Railway автоматически определит проект

6. **Настройте сервис:**
   - Railway может не определить папку автоматически
   - В настройках сервиса укажите:
     - **Root Directory:** `telegram-bot`
     - **Start Command:** `python bot.py`

7. **Добавьте переменные окружения:**
   - Перейдите в Settings → Variables
   - Добавьте:
     - `TELEGRAM_BOT_TOKEN` = ваш токен от BotFather
     - `MINIAPP_URL` = `https://spacegrowth.vercel.app/`

8. **Деплой:**
   - Railway автоматически задеплоит при push в GitHub
   - Или нажмите "Deploy" вручную

### 3. Проверка работы

1. Найдите вашего бота в Telegram
2. Отправьте `/start`
3. Должна появиться кнопка "🚀 Открыть Пространство развития"
4. Нажмите на неё — откроется ваш сайт как MiniApp!

## Команды бота

- `/start` - Начать работу с ботом
- `/help` - Справка
- `/site` - Открыть сайт Пространство развития
- `/diagnostics` - Пройти диагностику воронки

## Настройка кнопки меню в Telegram

После создания бота, настройте кнопку меню:

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/mybots`
3. Выберите вашего бота
4. Выберите "Bot Settings" → "Menu Button"
5. Выберите "Configure Menu Button"
6. Введите текст кнопки: `Открыть Пространство развития`
7. Введите URL: `https://spacegrowth.vercel.app/`

Теперь кнопка будет отображаться в меню бота!

## Мониторинг расходов

Railway показывает использование в реальном времени:

- Вкладка "Usage" покажет расход кредитов
