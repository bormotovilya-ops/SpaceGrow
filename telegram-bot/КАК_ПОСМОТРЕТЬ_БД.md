# Как посмотреть базу данных бота

## ⚠️ ВАЖНО: Где находится база данных?

База данных создается **там, где запущен бот**:

- Если бот работает **на сервере** (Railway, Heroku и т.д.) → БД на сервере
- Если бот работает **локально** (на вашем компьютере) → БД на вашем компьютере

## 📍 Ситуация 1: Бот работает на сервере

Если вы отправили `/start` боту и он ответил, но скрипт `view_db.py` не находит БД - значит бот работает на сервере, а не локально.

### Варианты решения:

#### Вариант А: Запустить бота локально (для тестирования)

1. **Создайте файл `.env`** в папке `telegram-bot`:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   MINIAPP_URL=https://spacegrowth.vercel.app/
   ```

2. **Установите зависимости** (если еще не установлены):
   ```bash
   cd telegram-bot
   pip install -r requirements.txt
   ```

3. **Запустите бота локально**:
   ```bash
   python bot.py
   ```

4. **Отправьте `/start` боту** в Telegram (когда бот работает локально)

5. **Запустите скрипт просмотра БД**:
   ```bash
   python view_db.py
   ```

#### Вариант Б: Подключиться к серверной БД

Если у вас есть доступ к серверу, где работает бот:

1. Найдите файл `bot_users.db` на сервере
2. Скачайте его к себе на компьютер
3. Положите в папку `telegram-bot`
4. Запустите `view_db.py`

## 📍 Ситуация 2: Бот работает локально

Если бот запущен на вашем компьютере (`python bot.py`):

1. **Отправьте `/start` боту** в Telegram
2. **Запустите скрипт**:
   ```bash
   cd telegram-bot
   python view_db.py
   ```

## 🔍 Проверка: Где работает бот?

### Признаки что бот на сервере:
- ✅ Бот отвечает на `/start`, но у вас не запущен `python bot.py`
- ✅ Скрипт `view_db.py` не находит БД
- ✅ В файлах есть `railway.json` или другие конфиги для хостинга

### Признаки что бот локально:
- ✅ В консоли видно: "Бот запущен!" или "Bot is running"
- ✅ В консоли видны логи: "Пользователь X создан/обновлен"
- ✅ Файл `bot_users.db` есть в папке `telegram-bot`
- ✅ Файл `bot.log` обновляется

## 🚀 Быстрый старт для локального запуска

1. **Перейдите в папку бота**:
   ```bash
   cd telegram-bot
   ```

2. **Создайте `.env` файл**:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   MINIAPP_URL=https://spacegrowth.vercel.app/
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите бота**:
   ```bash
   python bot.py
   ```

5. **В другом окне PowerShell запустите скрипт** (после отправки `/start`):
   ```bash
   cd telegram-bot
   python view_db.py
   ```

## 📝 Что делать, если БД все еще не найдена?

1. **Проверьте, что бот запущен локально**:
   - В консоли должно быть: "Бот запущен!"
   - В консоли должны быть логи при отправке `/start`

2. **Проверьте, создалась ли БД**:
   ```powershell
   ls telegram-bot\bot_users.db
   ```

3. **Проверьте логи бота**:
   ```powershell
   cat telegram-bot\bot.log
   ```

4. **Проверьте, что вы в правильной папке**:
   - Скрипт `view_db.py` должен быть в `telegram-bot\`
   - БД должна быть в `telegram-bot\bot_users.db`

## 💡 Подсказка

Если нужно тестировать механику напоминаний локально:

1. Запустите бота локально (`python bot.py`)
2. Отправьте `/start` боту
3. **НЕ открывайте miniapp** (чтобы проверить напоминание)
4. Подождите 1 минуту
5. Проверьте логи в `bot.log` или консоли
6. Запустите `view_db.py` чтобы увидеть статус
