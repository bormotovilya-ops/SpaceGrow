# 🚀 Как запустить бота локально для тестирования

## Пошаговая инструкция:

### 1. Создайте файл `.env`

В папке `telegram-bot` создайте файл `.env` со следующим содержимым:

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
MINIAPP_URL=https://spacegrowth.ru/
```

**Где взять токен:**
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/mybots`
3. Выберите вашего бота
4. Выберите "API Token"
5. Скопируйте токен

### 2. Установите зависимости

Откройте PowerShell в папке `telegram-bot` и выполните:

```powershell
pip install -r requirements.txt
```

Если pip не найден, используйте:
```powershell
python -m pip install -r requirements.txt
```

### 3. Запустите бота

В PowerShell выполните:

```powershell
python bot.py
```

Вы должны увидеть:
```
Логирование настроено. Логи сохраняются в bot.log
Планировщик задач запущен. Проверка напоминаний каждую минуту
Бот запущен!
```

### 4. Отправьте `/start` боту в Telegram

Когда бот работает локально, отправьте команду `/start` в Telegram.

В консоли должны появиться логи:
```
Пользователь X создан/обновлен в БД
started_at установлен на CURRENT_TIMESTAMP
```

### 5. Проверьте базу данных

В **другом окне PowerShell** (не закрывайте бота!) выполните:

```powershell
cd telegram-bot
python view_db.py
```

Теперь вы должны увидеть данные пользователя!

## ⚠️ Важно

1. **Не закрывайте окно с ботом** - пока бот работает, он обрабатывает сообщения
2. **Бот должен работать** чтобы БД обновлялась
3. **Один бот** - либо на сервере, либо локально. Если запустили локально, отключите на сервере (или наоборот)

## 🔍 Проверка что все работает

1. Бот отвечает на `/start` - ✅ работает
2. В консоли есть логи - ✅ работает
3. Файл `bot_users.db` создан - ✅ БД создана
4. Скрипт `view_db.py` показывает пользователей - ✅ все ОК!

## 📝 Тестирование механизма напоминаний

1. Запустите бота локально (`python bot.py`)
2. Отправьте `/start` боту
3. **НЕ открывайте miniapp** (чтобы проверить напоминание)
4. Подождите 1 минуту
5. Проверьте:
   - Логи в консоли бота
   - Файл `bot.log`
   - Скрипт `view_db.py`

## ❌ Если что-то не работает

**Ошибка: "TELEGRAM_BOT_TOKEN не найден"**
- Проверьте, что файл `.env` создан
- Проверьте, что токен указан правильно
- Проверьте, что `.env` находится в папке `telegram-bot`

**Ошибка: "ModuleNotFoundError"**
- Выполните: `pip install -r requirements.txt`

**Бот не отвечает**
- Проверьте, что токен правильный
- Проверьте интернет-соединение
- Проверьте логи в консоли и `bot.log`
