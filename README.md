# Пространство развития IT-Service

IT-сервис для создания автоматизированных интеллектуальных цепочек продаж для онлайн-обучения. Проект "Пространство развития" помогает экспертам масштабировать их бизнес через грамотную инженерию процессов и IT-решения нового поколения.

## 🚀 Публикация

Проект готов к публикации на **Vercel**. Подробная инструкция в файле [ДЕПЛОЙ.md](./docs/ДЕПЛОЙ.md)

## 📊 Аналитика (Яндекс.Метрика)

Метрика уже подключена в коде. Чтобы включить её, задайте переменную окружения `VITE_YM_COUNTER_ID` (ID счётчика).

- Локально и на Vercel: см. [ENV_SETUP.md](./docs/ENV_SETUP.md)
- Цели (reachGoal): см. [YANDEX_METRICA_GOALS.md](./docs/YANDEX_METRICA_GOALS.md)

### Логи переписки

- Локально логи пишутся в `logs/chat-YYYY-MM-DD.log`
- Для Vercel рекомендуется включить логирование в Google Sheets: см. [GOOGLE_SHEETS_LOGS_SETUP.md](./docs/GOOGLE_SHEETS_LOGS_SETUP.md)

### Быстрый старт:

1. **Git не установлен?** Скачайте с https://git-scm.com/download/win
2. **Инициализируйте Git:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   ```
3. **Создайте репозиторий на GitHub** и подключите:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```
4. **Деплой на Vercel:**
   - Войдите на https://vercel.com
   - Import Git Repository → выберите ваш репозиторий
   - Нажмите Deploy (настройки уже указаны в `vercel.json`)

## Структура проекта

- `src/` - React приложение (фронтенд)
- `backend/` - Python Flask API (бэкенд)
- `telegram-bot/` - Telegram бот с отложенными уведомлениями
- `api/` - API функции для Vercel
- `public/images/` - изображения
- `docs/` - документация проекта
- `scripts/` - вспомогательные скрипты
- `config/` - конфигурационные файлы
- `data/` - данные и контент
- `temp/` - временные файлы

## Установка и запуск

### Фронтенд (React)

```bash
npm install
npm run dev
```

Приложение будет доступно на http://localhost:3000

### Бэкенд (Python)

```bash
cd backend
pip install -r requirements.txt
python app.py
```

API будет доступно на http://localhost:5000

## Функционал

- Центральное фото с ссылкой на Telegram
- 6 элементов меню, расположенных по кругу:
  - **Что я делаю** — автоматизированные цепочки продаж, сайты, воронки, курсы
  - **Портфолио** — реализованные проекты и кейсы
  - **Отзывы** — отзывы клиентов и результаты
  - **Контакты** — способы связи
  - **Обо мне** — информация об архитекторе цепочек продаж
  - **Технологии** — как это работает
- Сайдбар с подменю при клике на элементы
- Адаптивный дизайн
- Стиль Apple Vision с glassmorphism эффектами

## Концепция

Создание технической части для продажи онлайн-продуктов (онлайн обучение):
- Сайты и лендинги
- Воронки продаж
- Обучающие курсы (в боте или GetCourse)
- Интеграция всех элементов в единую автоматизированную систему
