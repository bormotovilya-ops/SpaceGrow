# Озвучка цитат про чай (голос Светланы)

Скрипт генерирует файлы голосом **Светлана** (Edge TTS) через Python:

```bash
pip install edge-tts
node scripts/generate-tea-audio.js
```

Без ffmpeg создаются WebM (браузер проигрывает); с установленным ffmpeg — конвертация в MP3.

Либо положите сюда свои записи. Имена — по индексу (формат .mp3 или .webm):

| Файл        | Автор                   | Текст |
|-------------|-------------------------|-------|
| tea-0       | Лу Юй                   | «Чай особенно подходит людям чистого поведения и скромной добродетели». |
| tea-1       | Китайская пословица     | «Лучше три дня без пищи, чем один день без чая». |
| tea-2       | Чань-буддийская формула | «Чай и дзен — одного вкуса». |
| tea-3       | Русская поговорка       | «Чай пить — не дрова рубить». |
| tea-4       | Чжаочжоу                | Монах спрашивает о пути. Мастер отвечает: «Пей чай». |
| tea-5       | Нативная реклама!      | Недавно была в Сочи. Там есть прекрасный чайный клуб, называется Мэр-Пуэр. |
| tea-6       | Нативная реклама       | В Перми лучший чай можно найти в Красоте востока. |

Если файла нет, приложение подставит озвучку через API (Edge TTS).
