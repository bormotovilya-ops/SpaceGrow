# Озвучка цитат про чай (голос Светланы)

Скрипт генерирует файлы голосом **Светлана** (Edge TTS) через Python. Все 11 цитат должны быть озвучены и лежать в этой папке — иначе в кабинете часть цитат не будет открываться с озвучкой.

```bash
pip install edge-tts
node scripts/generate-tea-audio.js
```

Либо через npm:

```bash
npm run generate-tea-audio
```

Без ffmpeg создаются WebM (браузер проигрывает); с установленным ffmpeg — конвертация в MP3.
